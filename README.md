# Wanland Consumables Website

Professional company website for **Wanland Consumables**, based in Lae, Papua New Guinea.

**Live site (GitHub Pages):** once enabled — https://freddyamene.github.io/wanland-consumables/

## Contents

- `index.html` — Main page (Home, About, Products, Why Us, Contact)
- `styles.css` — Responsive dark professional theme
- `script.js` — Mobile menu + contact form (mailto)

## Adding product images

1. Create a folder `images/products/` in this repository.
2. Upload your product photos (JPG/PNG/WebP recommended).
3. In `index.html`, replace the placeholder `div.product-image.placeholder` blocks with:

```html
<div class="product-image">
  <img src="images/products/your-image.jpg" alt="Product name">
</div>
```

## Enabling GitHub Pages

1. Go to the repository **Settings → Pages**
2. Under **Source**, choose **Deploy from a branch**
3. Select branch `main` and folder `/ (root)`
4. Save. The site will be available at:
   `https://freddyamene.github.io/wanland-consumables/`
